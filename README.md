## Product constraints
- Persian and English (RTL/LTR).
- Game progress stays on the device; no cloud save.
- Supabase is for authentication only.
- Browser/PWA first; Android packaging later.
- Procedural 3D assets are preferred; Blender is not required.
- GitHub repository is Public by user decision.
